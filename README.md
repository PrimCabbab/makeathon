# Eudae (Astro)
npm install && npm run dev
- Story content: edit the `scenes` array at the top of src/pages/story.astro (put art in /public/art, set `art: '/art/scene1.png'`).
- Videos: src/data/videos.js (also feeds the "wrong choice" screen).
- Fonts: loaded from Fontshare in src/layouts/Layout.astro. To use your downloaded files, see the commented @font-face in src/styles/global.css.
- Colours: CSS variables at top of src/styles/global.css.
